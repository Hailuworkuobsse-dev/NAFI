# NAFI Frontend

**National Agri-Finance Infrastructure** — the digital backbone of Ethiopia's agricultural transformation.

## Structure

- `apps/` — Deployable applications (landing, web, farmer PWA)
- `packages/` — Shared workspace packages
- `services/` — Backend (Node.js + Prisma + MySQL)
- `e2e/` — Playwright end-to-end tests
- `docs/` — Documentation

## Getting started

```bash
pnpm install
pnpm typecheck
pnpm lint
pnpm test
```
